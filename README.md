# #️⃣ Документация Telegram-бота полуавтоматического гарант-сервиса (USDT TRC20)

Полуавтоматический гарант-сервис для безопасных сделок между пользователями в Telegram на базе **USDT TRC20 (сеть TRON)**.

---

## 🚀 Основной функционал

1. **Создание и сопровождение сделок**
   - Создание сделки покупателем или продавцом в личных сообщениях с ботом (`/create` или кнопка **«🤝 Создать сделку»**).
   - Создание сделки прямо в групповом чате (`/create` или `/deal`).
   - Привязка любого отдельного группового чата к сделке командой `/link <НОМЕР_СДЕЛКИ>`.
   - Приглашение второй стороны по прямой ссылке `https://t.me/<BotUsername>?start=deal_<ID>`.
   - Гибкое согласование условий, суммы, описания и плательщика комиссии (Покупатель, Продавец или 50/50).
   - Подтверждение условий обеими сторонами перед переходом к депозиту.

2. **Работа с USDT TRC20 и блокчейном Tron**
   - Использование **3 выделенных кошельков сервиса** с автоматическим распределением нагрузки.
   - **Автоматический трекинг входящих депозитов**: фоновый сервис непрерывно сканирует сеть TronGrid / TronScan по смарт-контракту USDT (`TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t`).
   - Привязка депозита к конкретной сделке и автоматическое изменение статуса на «Оплачено (В работе)».
   - Защита от повторных транзакций и двойных зачислений (учет в коллекции `payments`).
   - **БЕЗОПАСНОСТЬ:** Бот **не осуществляет автоматических выводов**. Выплаты продавцам и возвраты покупателям осуществляются **только вручную гарантом** после выполнения условий или урегулирования спора.
   - Проверка TXID исходящих переводов гарантом через блокчейн Tron перед фиксацией выплаты.

3. **Интерфейс и кнопки**
   - В личных сообщениях с ботом — удобные **Reply-кнопки** («🤝 Создать сделку», «📋 Мои сделки», «💼 Мой кошелек USDT», «ℹ️ Помощь», «⚙️ Админ-панель», «📊 Финансовая статистика»).
   - В групповых чатах — интерактивные **Inline-кнопки** под сообщениями.
   - Полная русскоязычная локализация (RU).

4. **Закрытый административный канал и управление**
   - Автоматическая публикация карточек сделок в закрытый канал администраторов при создании.
   - Динамическое обновление статусов и реквизитов в существующих сообщениях канала.
   - Кнопки быстрого управления для гаранта прямо в канале: «💸 Подтвердить выплату Продавцу», «↩️ Оформить возврат Покупателю», «⏸ Приостановить», «❌ Отменить сделку», «⚖️ Решить спор».
   - Рассмотрение споров и фиксация решений.
   - Финансовая статистика (общий оборот, прибыль, количество успешных сделок).

5. **Безопасность и конфиденциальность**
   - Разграничение прав ролей: Покупатель, Продавец, Гарант, Главный Администратор.
   - **Кошелек продавца конфиденциален:** скрыт от покупателя и публичного чата, виден только продавцу и гаранту в административном канале для проведения выплаты.
   - Полное журнальное логирование финансовых и административных действий в базе данных (`ActionLog`).

## 🛠 Установка и развертывание на VPS

### 1. Требования
- Ubuntu / Debian VPS
- Node.js v18+ или v20+
- MongoDB 6.0+

### 2. Клонирование и установка зависимостей
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd escrow_lite
npm install
```

### 3. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env_example .env
nano .env
```
Заполните параметры:
- `DB_CONN`: Строка подключения к MongoDB (например, `mongodb://127.0.0.1:27017/escrow_db`).
- `BOT_TOKEN`: Токен Telegram-бота от @BotFather.
- `ADMINS`: Telegram ID администраторов через запятую.
- `ADMIN_CHANNEL_ID`: ID закрытого канала гарантов (добавьте бота в канал администратором и укажите ID канала вида `-100xxxxxxxxxx`).
- `ESCROW_WALLET_1`, `ESCROW_WALLET_2`, `ESCROW_WALLET_3`: 3 кошелька USDT TRC20, на которые принимаются депозиты.
- `TRON_API_KEY`: (Опционально) API-ключ TronGrid для снятия лимитов запросов.

### 4. Запуск через PM2 или systemd
```bash
# Через PM2
npm install -g pm2
pm2 start bot.js --name tg_escrow
pm2 save
pm2 startup
```
